# SpringWell Bank

Next.js banking application with shadcn/ui, Convex, and Vercel.

## Tech Stack

- **Framework:** Next.js 16
- **UI:** shadcn/ui + Tailwind CSS v4
- **Backend:** Convex
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Convex Setup

```bash
npx convex dev
```

Follow the prompts to create a Convex project and link it to your app.

## Pages

- `/` - Homepage
- `/login` - Customer login
- `/register` - Account registration
- `/loan` - Loan application
- `/admin` - Admin dashboard

## Deploy to Vercel

```bash
vercel deploy
```

Or push to GitHub and connect to Vercel for automatic deployments.
